2 · Changes

RR-06 — Session lifecycle ✓

  • src/api/server.ts: private safeEqual() (length check + crypto.timingSafeEqual) on header and /events query path. Same accept/reject outcomes.
  • src/cli/cli.ts: new parseSessionFile() shape validation (port 1–65535, 48-hex token, optional pid); clearSessionFile() idempotent removal; getLiveSession() probes /health (1.2 s) and clears dead files so commands fall back to local paths.
  • run clears the file on both exit paths; serve clears on SIGINT/SIGTERM and closes the listener.
  • 6 new tests: test/security/session-lifecycle.test.ts.

RR-02 — Pack admission ✓

  • src/packs/packs.ts: corrupt/invalid registry and manifest failures now typed PackError with remediation (fail-closed before dispatch).
  • Own-key registry (Object.create(null) + Object.hasOwn); __proto__ schema-rejected; constructor/toString can never resolve via prototype.
  • Sidecar spawn: minimal env allowlist (PATH, SYSTEMROOT, COMSPEC, PATHEXT, TMP, TEMP), cwd = pack dir, error handler → PackError, stdin EPIPE guard, bounded child reaping.
  • 4 adversarial tests: test/packs/packs-admission.test.ts — RED 4/4 before, GREEN 4/4 after; no untrusted code executed.

Deliberately untouched: directive-after-close continuation (F-07), pack quarantine policy, gate/authority logic, console headers, path confinement. Detail: implementation-report.md.
